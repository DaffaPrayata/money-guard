# 🛡️ Money Guard - Personal Finance Assistant

**Money Guard** adalah aplikasi manajemen keuangan pribadi berbasis web dengan tampilan modern, *flat design*, serta dilengkapi dengan fitur **AI Guard Assistant** untuk membantu memantau pengeluaran dan pemasukan harianmu.

![Money Guard Banner](https://placehold.co/1200x600/1e3a5f/ffffff?text=Money+Guard+App)

---

## ✨ Fitur Utama

- 📊 **Dashboard Keuangan**: Pantau saldo total, pemasukan, dan pengeluaran secara langsung.
- 🤖 **Guard AI Assistant**: Tanya jawab seputar kondisi keuanganmu secara praktis melalui obrolan interaktif.
- 🗓️ **Kalender & Riwayat Transaksi**: Lacak riwayat transaksi berdasarkan tanggal dengan mudah.
- 💡 **Sistem Kategori & Akun**: Kelompokkan transaksi berdasarkan kategori dan jenis akun (*Cash*, *Bank Account*, dll).
- 🌓 **Dark Mode Support**: Tampilan tema terang & gelap yang nyaman di mata.
- 🔀 **Multi-Currency**: Dukungan berbagai mata uang (*IDR*, *USD*, dll).
- 📥 **Export Data (CSV)**: Unduh seluruh riwayat transaksimu ke format CSV kapan saja.

---

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan *tech stack* modern:

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.app)

## 🚀 Cara Menjalankan di Lokal (Development)

Jika kamu ingin mencoba dan mengedit project ini di komputer lokal:

### 1. Clone Repositori
```bash
git clone [https://github.com/DaffaPrayata/money-guard.git](https://github.com/DaffaPrayata/money-guard.git)
cd money-guard

```

### 2. Install Dependensi

```bash
npm install
# atau
pnpm install
# atau
yarn install

```

### 3. Jalankan Server Lokal

```bash
npm run dev

```

Buka [http://localhost:3000](http://localhost:3000) di browsermu untuk melihat hasilnya.

---

## 📦 Build untuk Production

Untuk memastikan tidak ada error TypeScript/Styling sebelum dipublish:

```bash
npm run build

```
